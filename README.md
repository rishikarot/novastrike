# NOVA STRIKE

A standalone, responsive arcade shooter with twelve levels, six targets, three bosses, touch and keyboard controls, and synthesized sound effects.

## Play

Open `index.html` directly in any modern browser. No dependencies, backend, build steps, or external assets are needed.

- Desktop: Left/Right or A/D to move; Space to shoot; P/Escape to pause.
- Mobile: Hold arrow buttons to move; hold FIRE to shoot.
- Pause, resume, start over and mute are available on screen.

## Publish on GitHub Pages

Create a repository, upload the `index.html` at the repository root, then enable Pages under Settings → Pages with "Deploy from a branch" and `main` / root selected.
